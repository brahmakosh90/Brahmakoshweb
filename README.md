# Brahmakosh Web Application

Welcome to the **Brahmakosh** Digital Ecosystem! This is a premium, cinematic spiritual wellness platform built to merge ancient Vedic wisdom with modern technology. The interface is meticulously designed to provide a "Warm Spiritual Luxury" experience.

## 🚀 Tech Stack

- **Framework:** React + Vite
- **Styling:** Vanilla CSS (Cinematic gradients, backdrop-filters, custom animations)
- **Animation Engine:** GSAP (GreenSock Animation Platform) + ScrollTrigger
- **Icons & UI:** Lucide React

## 📦 Getting Started

Follow these steps to run the application locally:

### 1. Install Dependencies
Make sure you have Node.js installed, then run:
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The application will launch on `http://localhost:5173/` by default.

### 3. Build for Production
To create an optimized production build:
```bash
npm run build
```
This will generate a `dist` folder containing the minified files ready for deployment.

## 🌍 Deployment Configuration

This repository includes built-in configurations to support seamless deployment to popular platforms:

- **Vercel:** Configuration provided in `vercel.json` to handle React SPA routing.
- **Netlify:** Configuration handled via `netlify.toml` (Build settings) and `public/_redirects` (Routing rules).
- Standard Single Page Application (SPA) routing is configured to fallback to `/index.html`.

## 🎨 Design Philosophy

- **Vibe:** Cinematic, luxurious, calm, and enlightened.
- **Core Elements:** High-contrast glow interactions, deeply layered 3D shadows, smooth easing curves, and a custom cinematic preloader.
